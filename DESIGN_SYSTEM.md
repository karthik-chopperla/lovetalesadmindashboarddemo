# LoveTales design system

**Colour.** Pure white `#FFFFFF` and warm white `#FAFAF8` surfaces; dark grey `#2C2C2C` primary text; vibrant orange `#FF6B35` actions and active navigation; peach `#FFE5D9` soft emphasis. Sage green `#6BA587`, warm amber `#F5A623`, coral red `#E74C3C`, and sky blue `#3B82F6` carry status meaning. All roles are mapped to semantic CSS tokens.

**Type.** Playfair Display for editorial headings and KPI numerals; Inter for interface labels, data, and controls. Body text is 14px; labels 12px; page headings 32px.

**Rhythm.** 8px spacing grid. 16–32px content spacing, 12–16px surface radius, hairline borders and soft warm shadows. Data stays visually quiet so event status and action hierarchy remain legible.

**Motion.** 200ms controls, 300ms overlay entrances, 1000ms ease-out KPI count-up. All movement is reduced when the system requests reduced motion.

**Components.** App shell, action buttons, metric cards, status badges, avatars, tabs, filters, search, tables, Kanban cards, drawers, confirmation dialogs, timeline, calendar, chart panels, toast notifications, loading skeletons, and empty states.
